# Budget

**Дашборд личного бюджета поверх Google-таблицы — KPI, инфографика, фильтры и история в двух валютах.**

[English version](README.en.md)

## Зачем

Бюджет ведётся в Google-таблице — это удобный ввод (руками или сообщением Telegram-боту), но неудобная аналитика: формулы хрупкие, срезы ограничены, история месяцев тонет. Budget оставляет таблицу единственным местом ввода, а всё остальное забирает на себя: данные автоматически синхронизируются в Postgres, и поверх них работает быстрый дашборд с фильтрами, графиками и пересчётом валют — таблицу можно вообще не открывать.

Два ключевых поинта: **(1)** таблица остаётся источником правды и не трогается, **(2)** вся аналитика — на сайте, за логином.

## Возможности

- **Синхронизация из Google Sheets** — сервис-аккаунт читает листы «Операции», «Категории» и «Курсы» и полностью перезаливает их в Postgres в одной транзакции: каждые 10 минут автоматически, по кнопке либо по защищённому API-вызову; статус последнего синхрона (время, число операций, ошибки) виден на дашборде.
- **KPI за период** — доход, расход и остаток по выбранному диапазону дат, с семантическими цветами и табличной вёрсткой цифр.
- **Динамика по дням** — area-график доходов и расходов за период.
- **Расходы по категориям** — donut-диаграмма (топ-8 + «Остальные») с легендой: доля в процентах и сумма по каждой категории.
- **Фильтры** — пресеты периода (текущий месяц / 30 дней / всё время), произвольные даты, тип (доход/расход), категория, текстовый поиск по описанию; всё состояние живёт в URL — любым срезом можно поделиться ссылкой.
- **Таблица операций** — список с датой, категорией, описанием и суммой со знаком, постранично.
- **Переключатель Сум/USD** — весь экран (KPI, графики, легенда, таблица) пересчитывается по актуальному курсу из листа «Курсы».
- **Вход по логину и паролю** — один пользователь, задаётся переменными окружения и сидируется идемпотентно при каждом деплое; смена секрета = смена пароля.

## Стек

Next.js 15 (App Router, standalone) + TypeScript + Prisma/PostgreSQL + Tailwind v4 + Recharts + NextAuth v5, деплой Docker-контейнерами на собственной VM за Caddy. Подробности — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Запуск локально

```sh
cp .env.example .env   # заполнить значения (БД, ключ сервис-аккаунта, id таблицы)
npm install
docker run -d --name budget-db -e POSTGRES_USER=budget -e POSTGRES_PASSWORD=budget \
  -e POSTGRES_DB=budget -p 5432:5432 postgres:16-alpine
npx prisma migrate deploy
node scripts/seed-user.mjs
npm run dev
```

Приложение поднимется на `http://localhost:3000`.

## Безопасность

Секреты — только в `.env` (не в коде и не в коммитах); в проде `.env` рендерится при деплое из self-hosted хранилища секретов (Infisical). Ключ сервис-аккаунта Google передаётся через переменную окружения (base64), файл не монтируется. Пароль входа хранится bcrypt-хешем; API синхронизации защищён Bearer-токеном. Правила подробнее — в [CONTRIBUTING.md](CONTRIBUTING.md).
